# Dataset

## Source

This project uses the **Online Retail** dataset from the UCI Machine Learning Repository.

The dataset contains transactional data from a UK-based online retailer and includes information such as invoice number, product, quantity, transaction date, unit price, customer identifier and country.

It contains more than 540,000 transaction records and is suitable for clustering and customer segmentation analysis.

## Why this dataset

The original Machine Learning exercise referenced an attached spreadsheet that was not available in the course materials.

To develop the project independently while preserving the original learning objective, the Online Retail dataset was selected as a real-world alternative suitable for customer segmentation with unsupervised learning.

## Data access

The original dataset is available from the UCI Machine Learning Repository:

https://archive.ics.uci.edu/dataset/352/online+retail

The raw dataset is not stored in this repository. Instructions for loading and preparing the data will be included in the project notebook.
