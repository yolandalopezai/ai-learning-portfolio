# Dataset

## Source

This project uses the **Credit Card Fraud Detection** dataset referenced in the original Machine Learning exercise.

The dataset is available on Kaggle:

https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

It contains anonymised credit card transaction data and includes a target variable indicating whether each transaction was classified as fraudulent or legitimate.

## Why this dataset

The dataset is particularly suitable for anomaly detection because fraudulent transactions represent a very small proportion of the total observations, creating a highly imbalanced real-world classification problem.

The project will use this imbalance to evaluate how unsupervised anomaly detection methods identify rare and unusual transaction patterns.

## Data Access

The raw dataset is not stored in this repository.

The project notebook will document how the data is loaded, explored and prepared for analysis.
